How it works

One command between your diff and a useful message.

1

Stage your changes

Choose exactly what belongs in the commit with the normal Git workflow.

2

Run Commit

The script sends the staged diff to your selected AI provider for a conventional message.

3

Review and commit

Accept the suggestion, regenerate it, or edit the message before anything is committed.

Get started

Install once. Use anywhere.

Bring your own Gemini or OpenAI API key. The installer checks the required command-line tools for you.

curl -s {{.Domain}}/install.sh | sh
curl -s {{.Domain}} | sh -- -k 'YOUR_GEMINI_API_KEY'

Use --ai-provider openai to switch providers, or --dry-run to preview without committing.
