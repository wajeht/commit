📝 Commit

Generate conventional commit messages with AI.

Basic Usage

git add .
curl -s {{.Domain}} | sh

Install

curl -s {{.Domain}}/install.sh | sh

How It Works

  1. Stage the changes you want to commit.
  2. Run Commit with your Gemini or OpenAI API key.
  3. Review, regenerate, edit, or accept the suggested message.

Options

-ai, --ai-provider
Choose gemini or openai. Defaults to Gemini.
-k, --api-key
Set the API key for the selected provider.
-dr, --dry-run
Preview the generated message without creating a commit.
-nv, --no-verify
Use the generated message without asking for confirmation.
-h, --help
Show command help.

Examples

curl -s {{.Domain}} | sh -- -k 'YOUR_GEMINI_API_KEY'
curl -s {{.Domain}} | sh -- --ai-provider openai --api-key 'YOUR_OPENAI_API_KEY'
curl -s {{.Domain}} | sh -- --dry-run
curl -s {{.Domain}} | sh -- --no-verify
